### **Target Learners :** 

This project explains Big Data and Connectionist AI to beginners with no background in the module. We are creating a Study Guide with a Test Bank, quizzes and games, PPT slides, and interactive game-style video tutorials with pop quizzes. All of them are built from the shared Markdown content in this repository. 

### **Learning goals :** 

We hope that by sharing our information about Big Data and Connectionist AI, a learner can  
a) Provide useful insight to beginners as simply as possible:

* Explain in their own words what big data is and describe the 5 Vs with an everyday example of each.   
* Explain what a neural network is and how it learns from examples, using a simple analogy. 

b) Teach them how to use connectionist AI efficiently:

* Describe what everyday AI tools (such as recommendations or image recognition) do well, and where they can make mistakes.   
* Give one example of how big data helps a neural network learn. 

c) Spread the precautions and rules about Big Data and Connectionist  AI. 

* Identify at least two data privacy risks (such as sharing personal information) and say how to protect themselves.   
* Explain what bias in data means and give one example of how it could lead to unfair results.

### **Scope**

* **Target Audience:** Beginners with little to no prior knowledge of Big Data or Connectionist AI.  
* **Content Coverage:** Introduces Big Data concepts, processing, analytics, and technologies, alongside Connectionist AI fundamentals, neural network architectures, and their combined applications.  
* **Learning Materials:** Provides a study guide, test bank, quizzes, games, PowerPoint slides, and interactive video tutorials with pop quizzes.  
* **Learning Focus:** Emphasises fundamental understanding, practical examples, responsible AI use, and awareness of data privacy, bias, and security.  
* **Learning Approach:** Uses simplified explanations, visual aids, and interactive activities to make complex concepts accessible to beginners.

### **Boundaries**

* **Technical Depth:** Excludes advanced mathematics, complex algorithms, and in-depth programming or model development. Brief code-style examples are used only to illustrate data formats, not to teach programming.  
* **Content Limitations:** Focuses on introductory concepts and selected applications rather than covering every Big Data technology or AI architecture.  
* **Practical Implementation:** Explains concepts and demonstrates examples but does not aim to build or deploy production-level Big Data systems or AI models.  
* **Ethical Considerations:** Introduces key concerns such as privacy, fairness, bias, and responsible use without providing an exhaustive legal or ethical analysis.  
* **Educational Purpose:** Serves as a supplementary learning resource and does not replace a comprehensive academic course or professional technical training.

One of the planned questions we made to conduct the quiz is as follows:   
Example question : Leo's family phone has 5,000 photos. That is a LOT of data. Which V is this?

1. Veracity (Is it TRUE?)  
2. Volume (how MUCH?)  
3. Value (is it USEFUL?)  
4. Velocity (how FAST?)

Learner activities: 

1. **Subtopic 1: The 5 Vs**

   #### **Learning objectives**

   #### After this lesson, a learner can:

1. **Name** the 5 Vs of big data: Volume, Velocity, Variety, Veracity and Value.  
2. **Explain Volume** as *how much* data there is.  
3. **Explain Velocity** as *how fast* data is made and moves around.  
4. **Explain Variety** as *many different kinds* of data, such as pictures, videos, text and music.  
5. **Explain Veracity** as *how true and correct* the data is.  
6. **Explain Value** as *how useful* the data is for making good choices.  
7. **Match** an everyday example to the correct V.  
     
   **QUIZ**

**Q1. Which pair is matched correctly?**

* A) Volume \= how MUCH data there is; Velocity \= how FAST data is made and moves ✅  
* B) Volume \= how FAST data moves; Velocity \= how MUCH data there is  
* C) Volume \= how TRUE the data is; Velocity \= how USEFUL the data is  
* D) Volume \= different KINDS of data; Velocity \= how TRUE the data is

*Why:* Volume is the amount of data, and Velocity is its speed. Think of a swimming pool: Volume is how much water it holds, and Velocity is how fast the tap fills it.

**Q2. Mia’s class collects photos, videos, and written notes. One of the notes has wrong numbers in it. Which two Vs describe these things?**

* A) Photos, videos and notes \= Velocity; wrong numbers \= Value  
* B) Photos, videos and notes \= Variety; wrong numbers \= a problem with Veracity ✅  
* C) Photos, videos and notes \= Volume; wrong numbers \= a problem with Variety  
* D) Photos, videos and notes \= Veracity; wrong numbers \= a problem with Velocity

*Why:* Many different kinds of data is Variety. Wrong numbers mean we can’t fully trust the data, which is a Veracity problem.

**Q3. A bakery keeps data about which cakes sell the most each day. Then it bakes more of the popular cakes so fewer are wasted. Which V is the bakery using?**

* A) Velocity, because the data moves fast  
* B) Variety, because there are many cake flavors  
* C) Value, because the data is helping make good choices ✅  
* D) Volume, because the bakery has a big oven

*Why:* Value is how useful data is. The bakery turns its data into a smart decision.

**Answer key:** Q1 \= A, Q2 \= B, Q3 \= C

**B. Subtopic 2: Evolution and Benefits**

#### **Learning objectives**

After this lesson, a learner can:

1. Explain that big data helps people and companies make better decisions, because they can look at facts and patterns instead of only guessing.  
2. Explain that big data helps things run more efficiently, meaning less waste, less time and lower cost.  
3. Explain personalization as using data about what a person likes to show them things that fit them, such as video or game suggestions.  
4. Describe the three steps in how data grew:  
   * Step 1: Traditional databases, which were neat tables of information.  
   * Step 2: The web, which brought pictures, videos and posts.  
   * Step 3: Cloud, phones and IoT, where “smart” devices and sensors constantly send data.  
5. Define IoT (Internet of Things) simply as everyday objects, such as watches and thermostats, that connect to the internet and send data.  
6. Match an everyday example to the correct benefit or step.

#### **Quiz**

**Q1. A school cafeteria keeps track of how many lunches get thrown away each day. Then it cooks only the amount that kids will really eat. Which benefit of big data is this?**

* A) Personalization  
* B) Better decisions and efficiency ✅  
* C) Slower data  
* D) Smaller data

*Why:* The cafeteria used data to decide better and waste less. That is better decisions and efficiency.

**Q2. Sam watches many dinosaur videos. Next time, a video app shows him more dinosaur videos. Which benefit of big data is this?**

* A) Personalization ✅  
* B) Efficiency in the kitchen  
* C) Slow storage  
* D) Wrong data (a Veracity problem)

*Why:* The app used Sam’s past choices to show things that fit him. That is personalization.

**Q3. Which list shows how data grew, from oldest to newest?**

* A) Traditional databases → the web → cloud, phones and IoT devices ✅  
* B) IoT devices → the web → traditional databases  
* C) The web → IoT devices → traditional databases  
* D) Cloud → traditional databases → the web

*Why:* Data started in neat database tables. Then the web added pictures, videos and posts. After that, cloud, phones and IoT devices sent data all the time.

**Answer key:** Q1 \= B, Q2 \= A, Q3 \= A

**C. Subtopic 3: Definition**

#### **Learning objectives**

After this lesson, a learner can:

1. **Explain** that big data is a huge collection of information, so large, fast and varied that a normal computer program or spreadsheet can’t handle it easily.  
2. **Describe** what makes big data “big”: lots of data (Volume), made very fast (Velocity), and in many kinds (Variety).  
3. **Give examples** of big data, such as social media posts, online shopping records and sensor data from machines.  
4. **Explain** that small data is a small amount of information that a person can look at and understand, such as a class survey or game scores.  
5. **Tell the difference** between big data and small data by looking at how much there is, how fast it comes in, and how many kinds there are.  
6. **Understand** that both kinds are useful: big data shows the big picture, and small data shows details.

#### **Quiz**

**Q1. What makes big data “big”?**

* A) It is written in very large letters  
* B) There is a huge amount of it, it comes in very fast, and it has many different kinds ✅  
* C) It can only be read by one person  
* D) It is always stored on a very big computer screen

*Why:* Big data is big because of its Volume (a huge amount), Velocity (it comes in very fast) and Variety (many kinds, like photos, videos and text).

**Q2. Which of these is an example of BIG data?**

* A) The scores from your class’s five spelling tests  
* B) A list of your 10 favorite foods  
* C) Millions of posts, photos and videos shared on social media every day ✅  
* D) A survey of 20 students about their favorite color

*Why:* Social media creates a huge amount of data, very fast, in many forms. The other choices are small enough for a person to look through easily.

**Q3. Ben asks 25 classmates which pet they like best and writes down the answers in a small table. What kind of data is this?**

* A) Big data, because it has answers from many people  
* B) Big data, because it is on a computer  
* C) Small data, because it is a small amount that a person can easily read and understand ✅  
* D) It is not data at all

*Why:* Small data is a small amount of information that people can understand without special computer systems. A class survey with 25 answers is a good example.

**Answer key:** Q1 \= B, Q2 \= C, Q3 \= C

**D.**  **Subtopic 4: Types of Data and Sources**

#### **Learning objectives**

After this lesson, a learner can:

1. **Explain structured data** as neat, organized data that fits in rows and columns, like a table of names and scores or a spreadsheet.  
2. **Explain unstructured data** as data with no set format, such as photos, videos, voice recordings, emails and social media posts.  
3. **Explain semi-structured data** as data that is a mix of both: it has labels that give it some order, but it isn’t a strict table. An email is one example, with labeled parts (From, Date, Subject) and a free-writing message.  
4. **Sort** everyday examples into structured, unstructured or semi-structured.  
5. **Name three sources of big data:**  
   * **Logs:** a computer’s “diary” of what it did and when.  
   * **IoT devices:** everyday objects like smart watches and sensors that connect to the internet and send data.  
   * **Transactions:** records of buying and selling, like store receipts.  
6. **Match** an everyday example to the correct source of data.

#### **Quiz**

**Q1. Which of these is structured data?**

* A) A photo from the school playground  
* B) A table in rows and columns with students’ names and their test scores ✅  
* C) A voice recording of a song  
* D) A funny video clip

*Why:* Structured data is neat and organized, like a table with rows and columns. Photos, voice recordings and videos have no set format, so they are unstructured.

**Q2. An email has labeled parts like “From,” “Date” and “Subject,” but the message inside can be written any way the sender likes. What type of data is an email?**

* A) Structured data only  
* B) Unstructured data only  
* C) Semi-structured data ✅  
* D) Not data at all

*Why:* The labels give the email some order, but the message itself is free writing. A mix of both is semi-structured data.

**Q3. Which match between an example and its data source is correct?**

* A) Smart watch counting steps \= IoT; store receipt \= transaction; a computer’s diary of what it did \= log ✅  
* B) Smart watch counting steps \= transaction; store receipt \= log; a computer’s diary \= IoT  
* C) Smart watch counting steps \= log; store receipt \= IoT; a computer’s diary \= transaction  
* D) Smart watch counting steps \= transaction; store receipt \= IoT; a computer’s diary \= log

*Why:* A smart watch is an everyday object that connects to the internet (IoT). A receipt records buying and selling (a transaction). A computer’s diary of what it did is a log.

**Answer key:** Q1 \= B, Q2 \= C, Q3 \= A

**E. Subtopic 5: Big Data vs Data Warehousing**

#### **Learning objectives**

After this lesson, a learner can:

1. **Explain** that a data warehouse is a big, organized storage place for information that has already been cleaned and put into neat tables.  
2. **Explain** that big data storage can hold all kinds of data (tables, photos, videos, text, sensor data), even if it is messy and not yet organized.  
3. **Compare the data structure:** a data warehouse keeps data in a neat, planned format, while big data storage accepts data in any format.  
4. **Compare how the data is stored:** a data warehouse organizes the data *before* putting it in, like a library with labeled shelves. Big data storage keeps the data in its raw form first, like a giant storage room, and organizes it later when needed.  
5. **Compare the typical use:** a data warehouse is used for clear reports and business decisions, such as how many items were sold last month. Big data is used to explore huge and varied data to find patterns, like predicting what people might like.  
6. **Choose** whether an everyday example sounds more like a data warehouse or big data.

#### **Quiz**

**Q1. Which sentence about data structure is correct?**

* A) A data warehouse stores neat, organized data, and big data storage can hold any kind of data, including messy data ✅  
* B) A data warehouse stores only photos and videos, and big data storage stores only numbers  
* C) Both can only store data in neat tables  
* D) A data warehouse stores any messy data, and big data storage allows only neat tables

*Why:* A data warehouse keeps data in a neat, planned format. Big data storage is built to handle many kinds of data, even messy data.

**Q2. A school librarian puts every book on a labeled shelf *before* anyone can borrow it. A giant storage room accepts boxes of all kinds of things, and people sort them later when they need something. Which matches how data is stored?**

* A) The library is like big data storage, and the storage room is like a data warehouse  
* B) The library is like a data warehouse, and the storage room is like big data storage ✅  
* C) Both are like a data warehouse  
* D) Both are like big data storage

*Why:* A data warehouse organizes data before storing it, like the library. Big data storage keeps raw data first and organizes it later, like the storage room.

**Q3. A shop manager wants a clear report that shows how many toys were sold each month. Which is the best fit?**

* A) A data warehouse, because it gives clear, organized reports for business decisions ✅  
* B) Big data storage, because it is only for pictures  
* C) Neither, because reports cannot use data  
* D) Big data storage, because a data warehouse cannot hold numbers

*Why:* Data warehouses are typically used for reports and business decisions based on neat, organized data. Big data is better for exploring huge amounts of varied data to find patterns.

**Answer key:** Q1 \= A, Q2 \= B, Q3 \= A
